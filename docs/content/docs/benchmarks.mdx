## Next LoCoMo Runs

Run multihop first:

```bash
zmem bench run locomo \
  --dataset data/locomo/locomo_official_zmem.json \
  --split default \
  --out .zerker/bench/locomo-official-v1 \
  --seed 42 \
  --run-id fts-multihop \
  --retrieval-mode fts-multihop
```

Then run hybrid/rerank:

```bash
zmem bench run locomo \
  --dataset data/locomo/locomo_official_zmem.json \
  --split default \
  --out .zerker/bench/locomo-official-v1 \
  --seed 42 \
  --run-id pseudo-embedding-rerank \
  --retrieval-mode pseudo-embedding-rerank
```

Why this order:

- `fts-multihop` tests whether query decomposition moves the weakest multi-hop and open-domain categories.
- `pseudo-embedding-rerank` tests whether reranking improves retrieval depth against the same fixed dataset and seed.
- The same `--out`, `--seed`, and dataset keep the comparison clean.

## Frontier Queue

Next benchmark priorities:

- LongMemEval-S: abstention and token-efficiency benchmark.
- LoCoMo `fts-multihop`: decomposition delta against the recorded FTS baseline.
- LoCoMo `pseudo-embedding-rerank`: reranking delta against the same baseline.
- BEAM: scale benchmark for 100K to 10M token memory pressure and causal traces.

Fast product fix to test:

- Add a deterministic abstention path when retrieved memory is empty or confidence is below threshold.
- Verify it against LoCoMo adversarial abstention and LongMemEval-S.

## Public Claim Rules

Allowed before official submissions:

- "ZMem publishes proof-backed local benchmark evidence."
- "This matrix is reproducible from the attached artifact hashes and receipts."
- "This local scaffold tracks retrieval accuracy, latency, tokens, and proof verification."

Do not claim official LongMemEval or LoCoMo ranking, vendor superiority, or canonical leaderboard score from local scaffold output.

## What To Track

- accuracy and category accuracy,
- recall and precision evidence where ground-truth support exists,
- p50, p95, and p99 retrieval latency,
- total tokens and injected context tokens,
- retrieved, injected, withheld, and budget-dropped memory counts,
- verification status,
- matrix hash and comparison hash,
- optional Treeship proof URL when public proof publishing is enabled.
