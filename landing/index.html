Agents need memory they can trust, not just retrieve.

The real pain is continuity with control. Agents lose memory between sessions, vector stores hide what was remembered, and summaries drift away from evidence. ZMem keeps memory local, queryable, reviewable, and attached to proof-backed receipts.

Know what it knows

Structured local memory with SQLite, FTS search, typed records, scopes, labels, source, trust, and authority.

Control what it uses

Agents can propose memory without making it authoritative. Humans or policies can promote, reject, quarantine, or revoke.

Verify the memory

Action receipts show what was injected, what was withheld, and which memory root backed the agent's decision.

Provenance and policy for the memory layer you already have.

Storage is not the hard part anymore. The hard part is knowing whether a stored memory should be allowed to shape a future action. ZMem records where memory came from, keeps risky memory reviewable, and gates retrieval through policy before an agent can use it.

Know the source

Track source kind, scope, labels, trust, authority, lineage, and lifecycle on every memory record.

Refuse unsafe recall

Similarity search finds candidates; policy decides what can influence a task, tool call, or handoff.

Answer incidents

When an agent acts, why and receipts show what it knew, where that memory came from, and why it was allowed.

Continue an agent without losing the audit trail.

Start on one agent, package the relevant memory state, restore it somewhere else, and prove what the next agent was allowed to use. The dashboard shows connected agent artifacts and the handoff path in one place.

Install locally. See everything.

Bootstrap ZMem, open the dashboard, then connect your agent. Codex and Claude Code get direct config installs; Cursor and other MCP clients get importable local packs plus a prompt that tells the agent when to inject, remember, and explain memory.

Start local
bash install.sh
zmem status --summary-only
zmem ui

For the verified first-run walkthrough, use bash examples/first_run.sh.

Connect agents
zmem agent install codex
zmem agent install claude-code
zmem agent install cursor --summary-only
zmem agent pack --summary-only
zmem doctor --agent codex --agent claude-code --agent cursor
zmem agent mcp-smoke --agent codex
1
Direct where possible

Codex writes to ~/.codex/config.toml; Claude Code writes to ~/.claude/mcp.json.

2
Import where safer

Cursor, OpenClaw, Hermes, and generic MCP clients receive project-local JSON, snippets, and checklists under .zerker/agents/.

3
Attach the agent prompt

.zerker/AGENT_PROMPT.md tells agents to call memory.inject, use only injected memory, write durable memory carefully, and call memory.why when memory shaped an action.
