Memory that survives the chat.

ZMem gives agents a local memory API: request approved memories before a task, propose new ones after, and hand verified state to the next agent.

Every memory-backed action can show what was used, what was withheld, and the Merkle root that verifies the memory set. Treeship can publish that receipt when you need a public proof URL.

Let the next agent continue with the same memory.

Start in Codex, move to Claude Code or Cursor, and keep the governed memory state intact. ZMem packages the snapshot, restore guide, receipt bundle, and prompt an agent needs.

Continuity path

Step 1
Remember locally

Store durable project, user, policy, or workflow memories in a local database agents can query.

Step 2
Serve approved context

Agents call memory.inject. Quarantined, revoked, or low-authority memory is withheld and recorded.

Step 3
Handoff with proof

Restore the same memory state somewhere else, then verify what the next agent was allowed to use.

Built for real agent memory pain.

Agent builders are converging on the same problems: agents forget, memory stores hide state, session handoffs fail, and summarized memory is useful but hard to audit. ZMem makes memory a tool agents can call and a record humans can inspect.

Install locally. See everything.

Bootstrap ZMem, open the dashboard, then connect your agent. Codex and Claude Code get direct config installs; Cursor and other MCP clients get importable local packs plus a prompt that tells the agent when to inject, remember, and explain memory.

Start local
curl -fsSL https://raw.githubusercontent.com/zerkerlabs/zmem/main/install.sh | bash
zmem status --summary-only
zmem ui

Prefer a cloned repo? Run bash install.sh, then use bash examples/first_run.sh for the verified walkthrough.

Connect agents
zmem agent install codex
zmem agent install claude-code
zmem agent install cursor --summary-only
zmem agent pack --summary-only
zmem doctor --agent codex --agent claude-code --agent cursor
zmem agent mcp-smoke --agent codex
1
Direct where possible

Codex writes to ~/.codex/config.toml; Claude Code writes to ~/.claude/mcp.json.

2
Import where safer

Cursor, OpenClaw, Hermes, and generic MCP clients receive project-local JSON, snippets, and checklists under .zerker/agents/.

3
Attach the agent prompt

.zerker/AGENT_PROMPT.md tells agents to call memory.inject, use only injected memory, write durable memory carefully, and call memory.why when memory shaped an action.

The roadmap builds from that foundation into signed memory transitions, memory quality scoring, semantic overlays, and shared team memory.
