ZMem gives agents persistent project memory across runs. Review what they learn, revoke what goes stale, and verify what shaped their work.

GitHub · Docs · Proof of work

Install locally. Verify before you trust it.

The installer creates the local workspace, runs the readiness checks, and generates the manual-agent pack. Agent config installs are explicit, so nothing is silently wired into your tools.

  1. Install ZMem. Run the installer. It creates the local environment, initializes .zerker, runs doctor, and prints readiness.
    curl -fsSL https://raw.githubusercontent.com/zerkerlabs/zmem/main/install.sh | bash
  2. Connect an agent. Install or export the MCP config for Codex, Claude Code, Cursor, OpenClaw, Hermes, or generic MCP.
    zmem agent install cursor --summary-only
  3. Prove the setup. Run the compact status check, agent smoke, or local UI before handing memory to real work.
    zmem status --summary-only

ZMem is the governed-memory half of the Zerker stack: Zerker Reason checks actions against facts a team has reviewed here, and Treeship signs the receipt.
